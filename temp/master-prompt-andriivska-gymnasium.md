## РОЛЬ

Ти — senior WordPress-розробник і product-дизайнер з 10-річним досвідом у сфері освітніх продуктів. Ти пишеш кастомні теми з нуля, знаєш theme.json і block editor до дрібниць, і ніколи не тягнеш page-builder туди, де вистачає нативних блоків. Ти створюєш не «шаблонний шкільний сайт», а живий, теплий цифровий простір закладу освіти, який зможе наповнювати вчитель інформатики без знання коду.

## ЗАВДАННЯ

Спроєктуй і реалізуй **кастомну гібридну block-тему WordPress** для Андріївської різнопрофільної гімназії (Україна). Результат — робочий код теми, а не опис.

**Технічні рішення (дотримуйся точно):**
- **Гібридна block-тема**: `theme.json` v3 + HTML-шаблони у `/templates` + PHP там, де потрібна логіка (CPT, ACF-поля, хелпери). Site Editor має працювати — редактор контенту міняє меню, кольори і тексти без розробника.
- **Без Tailwind.** Джерело істини для дизайн-токенів — `theme.json`. Він генерує CSS-змінні (`--wp--preset--color--brand`) і однакові стилі на фронті та в редакторі. Tailwind тут дублює систему, ламає паритет з Gutenberg і роздуває збірку.
- **CSS:** нативний, з `@layer`, кастомними властивостями і `clamp()`. Файлова структура — `/assets/css/` з розбивкою на `base`, `blocks`, `patterns`.
- **JS:** vanilla, модулями, `defer`. Без jQuery.
- **Іконки:** Lucide, inline SVG через PHP-хелпер `agz_icon( 'calendar' )` з `aria-hidden` і спрайтом. Без емодзі як іконок.
- **Мінімум:** WP 6.5+, PHP 8.1+. Без залежності від сторонніх page-builder'ів.

## КОНТЕКСТ І АУДИТОРІЯ

Три групи, у кожної свій сценарій за 10 секунд:
1. **Батьки** — «Куди подати документи? Який розклад? Хто вчитель мого класу? Як зв'язатися?»
2. **Учні** — «Розклад, новини, гуртки, дзвінки, фотозвіти».
3. **Перевіряючі / громада** — «Статут, ліцензія, кошторис, звіти, вакансії» (ст. 30 ЗУ «Про освіту» — прозорість та інформаційна відкритість).

Четверта, невидима аудиторія — **редактор контенту**: вчитель, який раз на тиждень додає новину з телефона. Якщо додати новину складніше, ніж пост у Facebook, тема провалена.

## ВІЗУАЛЬНА ДНК

Логотип — дерево, крона якого утворена з людських фігур, у колі з написом «Андріївська різнопрофільна гімназія». Метафора: **зростання, коріння, спільнота, природність**.

**Стиль:** organic minimalism — тепла мінімалістична база, м'які округлі форми (radius 12–24px), багато повітря, природні мотиви (листок, крона, гілка) як тонкі декоративні акценти, а не як клоуни на сторінці. Жодного скла, неонів, брутального чорного. Відчуття: світло, довіра, спокій, живе, доглянуте.

## КОЛІРНА СИСТЕМА → `theme.json`

Базові (обов'язкові):

| Slug | HEX | Призначення |
|---|---|---|
| `base` | `#F5F3EF` | Основний фон сайту (тепла кремова база) |
| `brand` | `#74BE5C` | Акцент: кнопки, активні стани, ілюстрації, крона |
| `ink` | `#443334` | Заголовки й основний текст (тепло-коричневий) |

Розширення палітри (виведене з базових, використовуй саме ці значення):

| Slug | HEX | Призначення |
|---|---|---|
| `surface` | `#FFFFFF` | Картки, поверхні поверх фону |
| `surface-alt` | `#EDEAE3` | Другорядні секції, зебра, скелетони |
| `brand-strong` | `#3F7A31` | **Зелений для тексту й посилань** — `#74BE5C` на світлому дає контраст ~2.2:1 і НЕ проходить WCAG |
| `brand-soft` | `#E8F3E3` | Заливки бейджів, hover-фони, теги |
| `ink-muted` | `#6B585A` | Другорядний текст, підписи, дати (контраст ≥ 4.5:1) |
| `line` | `#DFDBD3` | Бордери, роздільники |
| `accent-warm` | `#D98E4A` | Рідкісний акцент: терміново, дедлайни вступу |
| `danger` | `#B3413A` | Помилки форм |

**Правила кольору:**
- `#74BE5C` — тільки як **заливка** (кнопки з білим текстом, плашки, ілюстрації), ніколи як колір тексту на світлому фоні.
- Текст на `brand` — завжди `#FFFFFF` або `#1F2A1A`, перевір 4.5:1.
- У `theme.json` задай `settings.color.custom: false` і `customDuotone: false` — редактор не має можливості зламати палітру довільним кольором з піпетки.
- Оголоси `settings.color.gradients` з єдиним дозволеним градієнтом для героя: `linear-gradient(180deg, #F5F3EF 0%, #EDEAE3 100%)`. Решту вимкни.
- Колір ніколи не єдиний носій сенсу (статус дублюється іконкою чи текстом).

## ТИПОГРАФІКА → `settings.typography`

- **Заголовки:** `Onest` (600/700) — сучасний геометричний гротеск з повноцінною кирилицею.
- **Основний текст:** `Inter` (400/500) — максимальна читабельність на екрані.
- Підключай через **`settings.typography.fontFamilies` + `fontFace`** (self-hosted `.woff2` у `/assets/fonts/`, `font-display: swap`). Не через Google Fonts CDN — GDPR і швидкість.
- `fluid: true` у `settings.typography`, розміри через `fluid.min` / `fluid.max`:
  H1 2rem → 3.5rem; H2 1.5rem → 2.25rem; H3 1.25rem → 1.5rem; body 1rem → 1.0625rem; caption 0.875rem.
- Body на мобільному **мінімум 16px**. Line-height: 1.6 текст, 1.15–1.25 заголовки. Довжина рядка 65–75 символів (`--wp--style--global--content-size: 68ch` для текстових шаблонів).
- Українська типографіка: лапки «ялинки», тире —, нерозривні пробіли після коротких прийменників у заголовках.

## МОДЕЛЬ ДАНИХ (це серце теми)

Реєструй у PHP, з `show_in_rest: true` (інакше block editor їх не побачить):

| CPT | Slug | Поля / таксономії |
|---|---|---|
| Новини | `news` | таксономія `news_category`; обкладинка, дата, анонс |
| Педагоги | `teacher` | ACF: посада, предмет(и), кваліфікація, email; таксономія `subject` |
| Профілі навчання | `profile` | опис, іконка, класи |
| Документи | `document` | ACF: файл (PDF), дата оновлення; таксономія `doc_category` (статут, ліцензія, кошторис, звіти, вакансії) |
| Галерея / події | `event` | галерея зображень, дата |
| Розклад | `schedule` | ACF repeater: клас → день → уроки |

**Не** використовуй стандартні `post` для новин — залиш його вільним. ACF Pro або нативні `register_post_meta` + кастомні блоки; ACF допустимий, але тема має деградувати коректно, якщо плагін вимкнено.

## СТРУКТУРА ШАБЛОНІВ

```
/templates
  index.html            front-page.html       single-news.html
  archive-news.html     single-teacher.html   archive-teacher.html
  page-vstup.html       page-prozorist.html   archive-document.html

/parts
  header.html  footer.html  hero.html  quick-actions.html  news-latest.html
/patterns
  hero.php  quick-actions.php  profiles-bento.php  teachers-grid.php
  transparency-accordion.php  faq.php  contacts.php
```

**Хедер** (sticky, з відступом від краю, radius, тінь при скролі): логотип + назва · Про гімназію · Вступ · Навчання · Новини · Прозорість · Контакти · кнопка «Розклад» (brand) · перемикач «Версія для слабозорих». Меню — через `core/navigation` з зареєстрованим menu location, мобільний overlay нативний.

**Головна (`front-page.html`):**
1. **Hero** — коротка обіцянка (не «Ласкаво просимо!», а конкретика: чим гімназія відрізняється), 1 первинна CTA («Вступ 2026») + 1 вторинна, фото з м'якою маскою, тонкі листки з логотипу як декор.
2. **Швидкі дії** — 4 картки-ярлики: Розклад · Вступ · Документи · Контакти. Найважливіший блок: 80% користувачів прийшли саме за цим.
3. **Про гімназію** — 2–3 абзаци + 4 метрики (роки, учнів, вчителів, профілів).
4. **Профілі навчання** — bento-сітка через Query Loop по `profile` (різнопрофільність = ключова відмінність закладу).
5. **Новини та анонси** — Query Loop по `news`, 3 останні + «Усі новини». Дата, бейдж категорії `brand-soft`, обкладинка 16:9.
6. **Наші вчителі** — Query Loop по `teacher`, 4 превʼю.
7. **Життя гімназії** — галерея, lightbox (vanilla).
8. **Контакти** — карта (lazy iframe або статичне зображення з посиланням), адреса, телефон, години прийому, форма.

**Футер:** логотип, коротко про заклад, навігація в 3 колонки, соцмережі, «Протидія булінгу / гаряча лінія», кнопка «Нагору», копірайт.

## КАСТОМНІ БЛОКИ ТА ПАТЕРНИ

- Реєструй **block patterns** через `/patterns/*.php` з хедером-коментарем і `Categories: gymnasium`. Редактор збирає нові сторінки з готових секцій.
- Кастомні блоки (`@wordpress/scripts`, `block.json`, `apiVersion: 3`) — лише де патерна замало: акордеон «Прозорість», картка вчителя, таблиця розкладу, дзвінки.
- `theme.json` → `settings.blocks` — обмеж можливості редактора там, де він може зламати дизайн (спойлер: `core/paragraph` не потребує кастомного фону).
- Реєструй `styles/` варіації тільки якщо вони справді потрібні.

## UX-ВИМОГИ (критичні)

- **Адаптив:** перевір і зафіксуй 375 / 768 / 1024 / 1440px. Жодного горизонтального скролу. Mobile-first.
- **Тач:** усі клікабельні цілі ≥ 44×44px, `cursor: pointer` на всіх картках і кнопках.
- **Фокус:** видимий focus-ring (2px `brand-strong`, offset 2px), Tab-порядок = візуальному, skip-link «До основного вмісту».
- **Доступність WCAG 2.1 AA:** семантичні теги, `aria-label` для іконкових кнопок, `alt` для змістовних зображень і `alt=""` для декору, `<label for>` для всіх полів, помилки форм — текстом біля поля.
- **Версія для слабозорих** — обов'язкова для українських закладів освіти: збільшений кегль, підвищений контраст, вимкнені декоративні зображення. Клас на `<html>` + `localStorage`, перемикач у хедері, без FOUC (inline-скрипт у `wp_head`).
- **Анімації:** 150–300ms, тільки `transform`/`opacity`, hover без зсуву лейауту (колір/тінь/бордер, не `scale`), обовʼязково `@media (prefers-reduced-motion: reduce)`.
- **Продуктивність:** WebP + `wp_get_attachment_image()` зі `srcset`, `loading="lazy"` (крім героя — йому `fetchpriority="high"`), width/height завжди (без CLS). Ціль: LCP < 2.5s на 3G, бо частина батьків заходить з мобільного інтернету в селі.

## WORDPRESS-ГІГІЄНА

- Локалізація: text domain `agz`, усі рядки в `__()` / `esc_html__()`, `.pot` у `/languages`, українська — мова за замовчуванням.
- Екранування **завжди**: `esc_html`, `esc_url`, `esc_attr`, `wp_kses_post`. Форми — `wp_nonce_field` + перевірка `current_user_can`.
- `functions.php` — тонкий: тільки `require` файлів з `/inc/` (`setup.php`, `enqueue.php`, `cpt.php`, `blocks.php`, `patterns.php`, `helpers.php`).
- Стилі підключай через `wp_enqueue_style` з версією від `filemtime()`. Редактору — `add_editor_style()`, щоб фронт і бекенд збігалися.
- Дотримуйся WordPress Coding Standards, префікс `agz_` для всіх функцій.
- `style.css` з коректним хедером теми, `screenshot.png` 1200×900, `readme` з інструкцією для редактора українською.

## ЧОГО НЕ РОБИТИ (анти-патерни)

- Карусель у героя. Автоплей відео. Спливаючі вікна на вході.
- Elementor / WPBakery / Divi. Тема має жити без них.
- Стокові фото «усміхнені діти з планшетами» — тільки реальні або нейтральні плейсхолдери з підписом `[ФОТО: …]`.
- Синьо-жовті градієнти, стрічки, «шкільні» кліпарти, Comic Sans, тіні 90-х.
- Емодзі замість іконок. Текст поверх строкатого фото без затемнення.
- Хардкод кольорів у CSS повз `theme.json`. Хардкод текстів повз локалізацію. Запити в шаблонах повз `WP_Query`/Query Loop.
- Стіна тексту без заголовків. Меню з 12 пунктів. PDF як єдиний спосіб дізнатися розклад.
