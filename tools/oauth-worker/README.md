# OAuth-проксі для адмінпанелі

Маленький сервіс, без якого кнопка «Увійти через GitHub» в адмінпанелі
не працює. Розгортається один раз і далі про нього можна забути.

## Навіщо він потрібен

Сайт лежить на GitHub Pages — це статика, сервера немає. Щоб зберегти
зміну, адмінпанелі потрібен токен GitHub. Токен видається в обмін на
одноразовий код, і цей обмін вимагає `client_secret`. Покласти secret
у браузер не можна — його побачить будь-хто через «Переглянути код».
Тому потрібен посередник: цей воркер єдиний знає secret і віддає
браузеру вже готовий токен.

Cloudflare Workers на безкоштовному тарифі дають 100 000 запитів на добу.
Вхід у панель — це 2 запити. Тобто безкоштовно назавжди.

## Що всередині

| Файл | Що робить |
|---|---|
| `worker.js` | два маршрути: `/auth` (веде на GitHub) і `/callback` (міняє код на токен) |
| `wrangler.toml` | назва воркера й відкриті змінні |

Захист від CSRF: `/auth` кладе випадковий `state` у HttpOnly-cookie,
`/callback` звіряє його з тим, що повернув GitHub. Не збіглося — вхід
відхиляється.

## Розгортання

Покроково — у головному `README.md`, розділ **«Вхід модератора»**.
Коротко:

```bash
cd tools/oauth-worker
npx wrangler login
npx wrangler secret put GITHUB_CLIENT_SECRET
npx wrangler deploy
```

## Коли щось не працює

| Симптом | Причина |
|---|---|
| «Немає зв'язку із сайтом», `ERR_NAME_NOT_RESOLVED` на `*.workers.dev` | воркер ще жодного разу не розгорнуто. Субдомен `*.workers.dev` не існує до першого `wrangler deploy` — DNS не знаходить його тому, що знаходити нічого. Виконайте розгортання (три команди вище) |
| «Bad credentials» або порожня панель після входу | акаунт GitHub не має прав **Write** на репозиторій `olexiiv/gymnasium` |
| Вікно GitHub відкрилось і одразу закрилось, панель не пускає | `ALLOWED_ORIGIN` у `wrangler.toml` не збігається з адресою сайту |
| «Не збігається параметр state» | браузер блокує cookie; перевірте, що воркер відкривається через `https://` |
| «GitHub не видав токен» | неправильний `GITHUB_CLIENT_SECRET` — задайте ще раз через `wrangler secret put` |
| Вікно входу взагалі не відкривається | у `src/panel-8f2k/config.yml` не змінено `base_url` на реальну адресу воркера |
